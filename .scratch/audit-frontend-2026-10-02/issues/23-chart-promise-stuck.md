## Agent Brief

**Category:** bug
**Summary:** Rejeição do lazy-load do chart.js fica memoizada para sempre; uma falha transitória derruba todos os gráficos da SPA até hard reload.

**Current behavior:**
O setup dos gráficos memoiza uma única promise que importa `chart.js` e plugins. Se essa promise rejeita (rede fraca, offline momentâneo), a rejeição fica guardada no cache: toda chamada futura devolve a mesma promise rejeitada, mesmo com a rede restaurada. Um único erro de carregamento deixa todos os charts da sessão mortos até recarregar a página.

**Desired behavior:**
Uma falha transitória no carregamento dos chunks é recuperável: a próxima tentativa de uso dos gráficos re-importa os módulos e, com a rede disponível, renderiza normalmente. Sucesso continua memoizado (import dispara uma única vez por sessão em condições normais).

**Key interfaces:**
- Promise memoizada de setup do chart.js: em caso de rejeição, o cache é limpo (ou a promise é recriada) para permitir nova tentativa
- API consumidora pelos componentes de chart: inalterada — continua aguardando o mesmo setup e rejeitando quando o carregamento falha de fato

**Acceptance criteria:**
- [ ] Se o import rejeitar, uma chamada subsequente dispara novo import em vez de devolver a rejeição antiga
- [ ] Com rede disponível após uma falha, os gráficos renderizam sem reload da página
- [ ] Em condições normais, o import dos chunks ocorre apenas uma vez para N chamadas (memoização de sucesso preservada)
- [ ] Teste unitário simula rejeição seguida de sucesso e verifica a recuperação
- [ ] `lint`, `test:unit` e `build` passam

**Out of scope:**
- UI de erro/retry visível ao usuário
- Retry automático em background (basta permitir nova tentativa no próximo uso)
- Upgrade ou troca da versão do chart.js
