## Agent Brief

**Category:** enhancement
**Summary:** Remover a declaração direta de `vue-router` para eliminar a instalação duplicada (4.x + 5.x) no lockfile.

**Current behavior:**
O manifesto declara `vue-router` 4.x como dependência direta, mas o Nuxt usa 5.x — o lockfile instala as duas majors. Nenhum código do app nem teste importa `vue-router` diretamente (só os tipos gerados pelo Nuxt). Além de peso morto, a cópia 4.x é risco latente: qualquer resolução contra ela em vez da instância do Nuxt causaria comportamento de roteador quebrado, e a dependência declarada impede obter correções da 5.x pela via direta.

**Desired behavior:**
O lockfile contém uma única major de vue-router — a que o Nuxt resolver. O projeto não declara uma versão própria de roteador; quem precisar de roteador usa a instância/exportações compatíveis com a major do Nuxt.

**Key interfaces:**
- Manifesto: `vue-router` removido das dependencies diretas
- Lockfile: uma única major de vue-router resolvida
- Código do app/testes: nenhum import direto de `vue-router` fora dos tipos gerados

**Acceptance criteria:**
- [ ] Instalação resulta em uma única major de vue-router no lockfile
- [ ] Nenhum import direto de `vue-router` no código do app e testes (busca retorna zero fora de artefatos gerados)
- [ ] Instalação com lockfile congelado passa
- [ ] Build e testes unitários passam; navegação entre rotas do app funciona (smoke)

**Out of scope:**
- Atualizar o Nuxt
- Configurar ou refatorar o roteamento
- Resolver outras duplicações de dependência não abordadas aqui
