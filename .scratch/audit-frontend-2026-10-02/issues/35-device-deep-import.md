## Agent Brief

**Category:** enhancement
**Summary:** Eliminar deep imports do `node_modules` do @nuxtjs/device — consumir o composable pela superfície oficial do módulo.

**Current behavior:**
Dois arquivos de produção importam `useDevice` por caminho relativo profundo dentro de `node_modules`, contornando o exports map do pacote, e três specs mockam exatamente esse caminho. Isso quebra se o layout do pacote mudar (a major seguinte já mudou o exports map) e trava a atualização do @nuxtjs/device.

**Desired behavior:**
O código consome `useDevice` pela superfície oficial do módulo (auto-import do @nuxtjs/device), sem nenhuma referência a `node_modules` em imports ou mocks. Os testes mockam a mesma superfície que o código usa e continuam verificando o mesmo comportamento.

**Key interfaces:**
- `useDevice()` (@nuxtjs/device): consumir via auto-import do módulo, nunca por caminho interno do pacote
- Specs: o mock captura a superfície oficial que o código realmente usa, refletindo o import real

**Acceptance criteria:**
- [ ] Busca por `node_modules` em imports de produção e em mocks retorna zero
- [ ] Componentes/página continuam exibindo os dados do device corretamente (specs passam)
- [ ] Instalação com lockfile congelado, build e testes unitários passam

**Out of scope:**
- Atualizar @nuxtjs/device para a major seguinte (issue separada)
- Trocar de módulo de device/PWA
